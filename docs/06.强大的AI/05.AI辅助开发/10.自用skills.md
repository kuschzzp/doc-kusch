## 自用的全局 AGENTS.md

```markdown
# Strictly observed rules
1. When the user does not specify the reply language, always reply to the user in Chinese.
2. When you are writing code, you must first check the latest content of the file you need to modify before starting to write.
3. If you activate the temporary debugging program during this writing process, you must shut it down after the execution is completed!
4. If you create additional temporary folders during this writing process, you must delete them after the execution is finished!
5. If a browser is required, use the codex built-in browser by default.
6. Before executing a task, determine whether it is appropriate to split the task into separate subagents, and if so, execute it as a subagent.
7. Without the user's permission, it is strictly prohibited to use git to commit or push any content!
8. When executing tests, simple tests can be executed, complex page tests must ask for user consent, otherwise a lot of tokens will be wasted!
9. If the user is using `Jetbrains` series of development tools, it is recommended to immediately check if there is an mcp tool corresponding to the development tools in the MCP tool. If there is, when running the code and conducting tests, the tool should be invoked first instead of directly running the command.
```

## (旧)自用SKILL记录 ---- uninstall all in 2026-09-24

**过往模型可以安装这些SKILL，目前就 GPT6 Astra 来看, 安装这些非定制化的SKILL，反而拖慢执行速度，浪费token。**  

下面是安装在全局的几个技能，相较于直接安装全量 superpowers 会节省一些token。

> npx skill 使用  [https://www.npmjs.com/package/skills](https://www.npmjs.com/package/skills)  
> 下面的都是安装在codex上。

- 头脑风暴，编程开始前提出想法验证想法，需求澄清。
```shell
npx skills add https://github.com/obra/superpowers -g --skill brainstorming -a codex
```

- 规划 计划、任务待办，按照文件维度设计修改思路。

**这里还可以去把superpowers里面的有关subagent的几个skill安装一下，提速编码，但我觉得没必要**

```shell
npx skills add https://github.com/obra/superpowers -g --skill writing-plans -a codex
```

- 让AI做架构设计，复杂项目领域建模 （实现干净的架构、六边形架构和领域驱动的设计）
```shell
npx skills add https://github.com/wshobson/agents -g --skill architecture-patterns -a codex
```

- 微服务架构设计
```shell
npx skills add https://github.com/wshobson/agents -g --skill microservices-patterns -a codex
```

- 前端项目设计优化，不是专门做“页面设计”的工具，但会影响页面结构和实现方式
```shell
npx skills add https://github.com/vercel-labs/agent-skills -g --skill vercel-react-best-practices -a codex
```

- 前端编程可扩展编码设计模式
```shell
npx skills add https://github.com/wshobson/agents -g --skill design-system-patterns -a codex
```

- 页面视觉UI设计
```shell
npx skills add https://github.com/nextlevelbuilder/ui-ux-pro-max-skill -g --skill ui-ux-pro-max -a codex
```

- 页面排版设计
```shell
npx skills add https://github.com/wshobson/agents -g --skill visual-design-foundations -a codex
```

- 让AI写的文档更好看，像纸质报纸一样。开源项目：[https://github.com/tw93/Kami](https://github.com/tw93/Kami)
```shell
npx skills add tw93/kami -a codex -g -y
```

> 删除：npx skills remove --global xxxx名字xxxx  
> 更新：npx skills update -y
